# Roadmap

## MVP actual

- Feed vertical responsive.
- Composer con preguntas dinámicas.
- Categorías, modos, nivel viral y menciones.
- Notificación visual inmediata al mencionar amigos.
- Rutas compartibles.
- API base para preguntas, feed, respuestas y notificaciones.
- APIs de reacciones, reportes, bloqueos e invitaciones.
- Open Graph dinámico por respuesta.
- Capa repositorio con Prisma y fallback demo.
- Prisma schema completo para producción.
- Auth social preparado.
- Moderación inicial.

## Próximo sprint

- Conectar Prisma real en API routes.
- Añadir sesión real de NextAuth en UI.
- Implementar Redis pub/sub y Socket.io persistente.
- Generar imágenes Open Graph dinámicas con Cloudinary.
- Añadir reportes/bloqueos desde la interfaz.
- Añadir rate limiting por usuario e IP.

## V1

- Push notifications web.
- Rankings por ciudad, escuela, grupo y semana.
- IA generadora de preguntas con panel de aprobación.
- Stories exportables 9:16.
- Modo fiesta con sala y código QR.
- Modo pareja con privacidad reforzada.

## V2

- App móvil React Native o Expo.
- Marketplace de themes.
- Creator tools para retos.
- Moderación IA multimodal.
- Programa de embajadores.
